# Software Design Patterns — Assignment 2

This project demonstrates two creational design patterns in Java:

- **Part A — Factory Method:** a logistics system for creating different types of transport.
- **Part B — Abstract Factory:** a UI component system with Modern and Old design families.

## Project Structure

- `Part-A/` — Factory Method implementation
- `Part-B/` — Abstract Factory implementation

Each part contains its own `Main.java` file used to demonstrate the pattern.

## How to Run

Open the required part in IntelliJ IDEA or another Java IDE and run:

- `Part-A/Main.java` for the Factory Method demonstration.
- `Part-B/Main.java` for the Abstract Factory demonstration.

## Requirements

- Java JDK 17 or later
